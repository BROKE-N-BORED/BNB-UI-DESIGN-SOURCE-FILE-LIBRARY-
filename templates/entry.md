# Entry template

The exact shape every new entry follows. Copy this file, rename it to the
next free number plus slug (`entries/NNN-slug.md`), and fill it in. Then
add it to `INDEX.md` (alphabetical, by topic, by app) and note it in
`CHANGELOG.md`.

```md
# NNN — <Name>

> Entry NNN — added <YYYY-MM-DD> (Drop N: <drop name>).

*<tagline, one line>*

**What it is.** ...

**Why it feels good.** ...

**The numbers.** ... (exact figures from the sources; if the source gives
no number, state the mechanism instead)

**Where it fits his apps.** ...

**Watch out.** ...

## See also

- [NNN <Name>](NNN-slug.md)
- ...

## Sources

- <Title>, <publication>, <date> — <URL>
- ...
```

## Standing rules

- Sourced and dated. Every entry carries the sources its numbers and
  mechanisms came from, and the date it was added.
- The numbers rule: every figure must be cited from a source actually
  opened. Where a source gives no number, state the mechanism instead —
  never invent.
- The toy test (U34): a child could pick it up and use it. If the
  technique needs explaining, it doesn't go in.
- The filter lives only in the README. Never copy it into an entry.
- Numbers are permanent IDs. Never renumber, never reuse a number.
- Optional: a History line when the origin matters (who coined it, when,
  where it came from).
