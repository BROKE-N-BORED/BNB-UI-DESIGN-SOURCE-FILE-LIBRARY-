# 014 — Teach by playing

> Entry 014 — added 2026-11-13 (Drop 2: Games, editors, and gadgets).

*onboarding with no tutorial text*

**What it is.** The game never stops to explain itself. The first minute
of play IS the tutorial: a constrained space where only the core action
exists, feedback the instant you act, and one new idea at a time. Mario
1-1 teaches movement, enemies, and jumping in about 15 seconds with no
text. Celeste has you jumping in the first 4 seconds. Vampire Survivors
spends its first two minutes as guided discovery: slow enemies, automatic
weapons, you cannot lose yet. By the time real decisions arrive, you have
already learned the loop by doing it.

**Why it feels good.** A tutorial says learning comes before fun. Play
says they arrive together. Players tap through text prompts as fast as
the UI allows, then get confused by something the tutorial never covered.
The tutorial did not orient them; it delayed the moment of actual contact
by 45 seconds. When the environment does the teaching, there is nothing
to skip and nothing to forget.

**The numbers.**
- Mario 1-1: movement, enemies, jump, about 15 seconds, no text.
- Celeste: jumping in the first 4 seconds. Stardew Valley: moving within
  90 seconds.
- The first-60-seconds test: if a new player cannot do the core thing
  inside a minute, the opening is the problem, not the player.
- Feedback within half a second for every action in the first 90 seconds.
  Longer than that and players form wrong mental models.
- A hint becomes useful after the player has been stuck 90 seconds, not
  before. Retry in 3 seconds turns a failure into information.
- Tutorial completers retain at up to 25 percent on Day 30, against 8
  percent for cohorts that skip it (Countly, 2026). The 2026 median
  mobile game keeps 22 percent of players on Day 1.
- The honest limit: 6 or more distinct actions genuinely need text. Below
  that, play can carry it.

**Where it fits his apps.** Yahtzee (the first game teaches itself: one
roll, one choice, the scorecard fills in as you go), Pixel Forge (the
first image opens with one tool in hand, not a tour), STELLA (the first
run is a real tiny run, not a setup wizard), Code Forge (the first prompt
is the tutorial; the empty state is a working example, not a manual).

**Watch out.** One mechanic at a time, and never introduce a second before
the first has been used successfully. A skipped tutorial is a design
failure, not a user failure. And the first safe failure teaches more than
the first guaranteed win: let the user fail once, early, for a reason
that is legible and fixable on the next try.
