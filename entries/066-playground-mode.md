# 066 — Playground mode

> Entry 066 — added 2026-11-14 (Drop 6: Structure, comfort, and trust).

*Break it here, so you never break it there.*

**What it is.** A playground is a safe copy of the real thing: real tools, real data, nothing saved, nothing counted. Figma ships playground files with plugins and widgets: click Try it out on the Community page and the file is duplicated into your drafts, preloaded with material to try the tool on, like a spell-check plugin's file full of misspelled text. Figma's own education files do the same for features: the Layout Grids file puts tasks on the canvas itself, "Try deleting this element and watch how the rest of the design shifts," "Stretch this button," "Change the variable value and see how the entire system updates." Miro's Miroverse boards offer playgrounds per skill, an engage playground for sticky notes and voting, an AI playground for auto-generated diagrams. Notion's Welcome page is a live document you can check, type in, and bold, a draft you can break. Code playgrounds work the same way: the TypeScript Playground opens in the browser with no install and no config, and a Share button that encodes the code, compiler settings, and tab state into a link; SQLBolt's lessons each end with an exercise you run in the browser on a real little database. Games have had this for years: Rocket League's Free Play drops you in an arena with nothing but the ball, no time limits, no targets, and a goal just resets you to a starting position.

**Why it feels good.** Fear is what keeps a new user from touching anything, and a playground removes the fear instead of the controls. The canvas is already populated, so there is no blank page to dread. The data is real, so what you learn transfers to real work. The first moves are guided, one small task at a time, so the user is doing the thing within seconds instead of reading about it. And the reset is always one click away, so an experiment that goes wrong costs nothing. A tutorial tells you; a playground lets you find out, and what you find out by doing is what sticks.

**The numbers.** Figma's AI Playground file, a guided sandbox built for the Figma AI launch, drove 30 percent feature adoption within its first month across Figma's global user base, as reported by its co-creator. Rocket League's Free Play has no time-sensitive targets at all, while its drilled modes put the ball on a roughly 10 second clock, a clean statement of the difference between play and drill. The TypeScript Playground's share link carries the whole state, code plus compiler settings plus tab state, so a playground moment can be handed to someone else exactly as you left it. Where no number exists, the mechanism is the spec: real data, nothing saved, one-click reset, guided first moves. A playground with fake data teaches fake lessons; a playground with no reset teaches caution, which is the opposite of the point.

**Where it fits his apps.** ACR: a playground run with a sample file preloaded and every resonance pack available to try, with a Reset button that restores the sample. MIMIK: a practice capture, a sample clip to scrub, cut, and annotate, with nothing written to the library. GITDATA: a demo dataset to query, filter, and sort, with a reset that restores it. Qwkhnd: a demo board with sample tasks to triage, so the first real triage is the second time through. Pixel Forge: a sample image with one tool in hand, the playground version of 014's first image. Reblend: a starter scene to push materials around in, distinct from 054's starter content because nothing here is kept. LYNX SHARE: a demo song to mangle, with reset restoring the original mix. Qt fit: a playground is a second session state, not a second app, so it costs almost nothing on his PC; the reset is a reload from the bundled template, and the playground window needs a clear label so play is never mistaken for work.

**Watch out.** A playground must say it is a playground, on screen, or a user will do real work in it and lose it, or do play in the real app and break something. Never gate the real app behind the playground: it is a door, not a corridor, and an expert should never have to pass through it. Keep the guided moves short, one task at a time, and never let them harden into a tour with a progress bar. Do not save playground state into the real project, and do not let the playground's reset button sit next to a destructive action. And do not build the playground on toy data: the Figma spell-check file works because the misspellings are real mistakes in real text, and a playground built on lorem ipsum teaches nothing about the real tool.
